# 课时薪资计算（移动端 PWA）设计文档

- 日期：2026-08-10
- 状态：待用户审阅
- 范围：单老师个人使用的课时薪资统计工具

## 1. 背景与目标

老师本人需要按"课时薪资"计算每月收入：每节课按**时薪 × 小时数**计薪，
支持从 Excel 课程表导入上课记录，按月汇总收入，并支持数据备份与恢复。
核心要求：**数据本地离线、完全安全**，且**手机上可用**（Android + iPhone 双兼容）。

## 2. 已确认的业务规则

| 编号 | 规则 | 结论 |
|---|---|---|
| R1 | 计薪口径 | 课程单价 = 时薪（元/小时）；薪资 = Σ(单价 × 小时数) |
| R2 | 使用人 | 单老师个人，不涉及多老师分摊 |
| R3 | 每节小时数 | Excel 时间区间优先（`13-15`→2h，`13:00-15:30`→2.5h）；缺失/解析失败时用课程类型配置的"默认课时"；两者皆无 → 标记"异常" |
| R4 | 课程类型字段 | 名称 + 教学形式 type（一对一/小班/线上等）+ 状态（启用/停用）+ 默认课时 + 默认时薪 |
| R5 | 记录管理 | 导入后支持编辑、标记取消（不计薪）、删除、手动补录单条 |
| R6 | 导入 | 容错解析：表头识别列、日期/时间多格式、忽略空行、多 sheet 自动找表头、未知课程类型可自动创建；提供导入模板下载 |
| R7 | 汇总 | 按月：总收入、总课时、按学生/课程类型/教学形式分组、取消课单列 |
| R8 | 导出 | 全部数据导出 Excel（可再导回=备份恢复）；月报导出 Excel |
| R9 | PIN 锁 | 需要；打开 App 时输入，数据仍完全本地 |
| R10 | 设备 | Android + iPhone 双兼容，移动端优先布局与交互 |

## 3. 技术方案

- **形态**：纯前端 PWA（Progressive Web App），可"添加到主屏幕"安装，安装后离线可用。
- **数据存储**：手机浏览器本地 IndexedDB（通过 Dexie.js 封装）；无后端、无账号、无网络请求，数据不出手机。
- **技术栈**：Vite + React + TypeScript + Dexie.js + SheetJS（xlsx）+ vite-plugin-pwa（Workbox 离线缓存）+ Web Crypto（PIN 哈希）。
- **托管**：一次性部署到免费静态托管（GitHub Pages 或 Cloudflare Pages），HTTPS 提供 PWA 安装能力；服务器只托管前端文件，不接收任何数据。
- **备份**：Excel 导出/导入即备份恢复，文件由用户自行保管（手机/网盘/电脑均可）。

## 4. 数据模型（IndexedDB）

### 4.1 course_types 课程类型
| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 自增/时间戳 ID |
| name | string | 课程类型名称，如"初三数学1对1" |
| type | string | 教学形式，如"一对一/小班/线上" |
| status | 'enabled' \| 'disabled' | 启用/停用；停用不影响历史统计，仅新建/导入默认不再优先推荐 |
| default_hours | number | 默认课时（小时），导入时间缺失时兜底 |
| default_rate | number | 默认时薪（元/小时），导入单价缺失时兜底 |
| created_at | string | 创建时间 |

### 4.2 records 上课记录
| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | ID |
| course_type_id | string | 关联课程类型；类型被删时保留快照字段 |
| course_type_name | string | 快照：课程类型名称 |
| course_type_kind | string | 快照：教学形式 |
| rate | number | 时薪（元/小时），导入/手动时确定 |
| student | string | 学生名称 |
| date | string | 上课日期 `YYYY-MM-DD` |
| start_time | string \| null | 开始时间 `HH:mm`，可空 |
| end_time | string \| null | 结束时间 `HH:mm`，可空 |
| hours | number | 本节小时数（计算后固化，编辑时间时重新计算） |
| status | 'normal' \| 'cancelled' | 正常 / 已取消（不计薪） |
| source | 'import' \| 'manual' | 来源 |
| batch_id | string \| null | 导入批次号 |
| note | string | 备注 |
| created_at | string | 创建时间 |

金额不落库，始终由 `rate × hours` 计算，避免冗余不一致；状态为 cancelled 时不计入汇总。

### 4.3 import_batches 导入批次
| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 批次 ID |
| filename | string | 原文件名 |
| file_hash | string | 文件内容指纹（用于重复导入提示） |
| imported_at | string | 导入时间 |
| row_count | number | 成功导入行数 |

### 4.4 settings 设置
| 字段 | 类型 | 说明 |
|---|---|---|
| key | string | 如 `pin_hash`、`pin_salt`、`last_month` 等 |
| value | any | 值 |

## 5. 功能页面（移动端优先）

底部 Tab 导航（≤4 个），单页状态切换（不引入路由库）：

1. **汇总（首页）**
   - 月份选择器（上/下月箭头 + 月份快捷选择）
   - 顶部摘要卡：总收入、总课时、有效课次、取消课次
   - 分组列表：按学生 / 按课程类型 / 按教学形式（Tab 切换），每组显示课次、总课时、金额
   - "已取消"区单独折叠展示
   - 按钮：导出本月 Excel
2. **上课记录**
   - 按月列表，卡片显示：日期、时间段、学生、课程类型、时薪、金额、取消标记
   - 点卡片 → 底部弹出编辑面板（Bottom Sheet）：日期/时间段/时薪/学生/课程类型/状态/备注
   - 左滑或长按 → 删除/取消/恢复；提供"手动补录"浮动按钮
3. **导入**
   - 顶部提供"**下载模板**"按钮：生成含表头 + 2 行示例数据的 Excel 模板（列：课程类型 | 课程单价 | 学生名称 | 上课日期 | 上课时间），方便按规范整理课程表
   - 选文件（Android 系统文件选择器 / iPhone 文件 App）
   - 解析预览页：识别到的列映射、总行数、异常行（红）、重复行（黄）、将新建课程类型（蓝），可逐行勾选跳过
   - 确认导入 → 入库 → 提示结果；提供"撤销本批导入"
4. **课程类型**
   - 列表（启用/停用分组），新增/编辑表单：名称、教学形式、状态、默认课时、默认时薪
5. **设置**
   - 导出全部数据（Excel，含课程类型与记录，可再导入恢复）
   - 导入恢复（从备份文件还原，覆盖/合并选择）
   - PIN 锁设置/修改/关闭
   - 关于/版本

## 6. 导入解析规则（容错）

- **表头别名识别**：
  - 课程类型：`课程类型`/`课程`/`科目`/`类型`
  - 课程单价：`课程单价`/`单价`/`时薪`/`价格`/`课时费`
  - 学生名称：`学生名称`/`学生`/`姓名`
  - 上课日期：`上课日期`/`日期`
  - 上课时间：`上课时间`/`时间`/`时间段`
  - 列顺序任意、多余列忽略；多个 sheet 时自动找含表头且数据最多的 sheet。
- **日期**：支持 `2026-08-10`、`2026/8/10`、`08-10`（缺年份补当前年）、Excel 原生日期单元格；解析失败 → 异常行。
- **时间**：支持 `13-15`、`13:00-15:00`、`13:00-15`、`13:00~15:30`；分隔符 `- / ~ / — / 至`；结束早于开始按跨天 +24h；只有开始无结束 → 用课程类型默认课时；全空 → 用默认课时；无法解析 → 异常行。
- **小时数计算**：`(end - start)` 换算小时（半点支持 0.5）；结果固化到 records.hours。
- **单价**：支持纯数字、带 `元/¥`；留空 → 课程类型默认时薪；与课程类型默认不一致 → 预览标黄提示（不阻断）；都为空 → 异常行。
- **课程类型匹配**：按名称精确匹配配置；未匹配 → 预览提示"将自动创建（启用，默认课时/时薪取该行值）"，可勾选跳过。
- **重复导入**：同批次文件指纹重复 → 整文件提示；行级重复（同日期+学生+时间段+课程类型）→ 预览黄标，可勾选跳过。
- **示例行识别**：模板内学生名称以「示例」开头的行，在预览中默认取消勾选，避免示例数据误入真实记录。
- **导入预览确认后**才写库；入库后可在记录页修改，也可整批撤销。

## 7. 计算与汇总逻辑

- 单条金额 = `rate × hours`（normal 状态）。
- 月度汇总 = 该月全部 normal 记录求和；分组按学生/课程类型/教学形式分别聚合（课次、总课时、金额）。
- 取消课不计入收入与课时，但单列显示（含金额，便于核对）。
- 全部为前端本地计算，无精度问题：金额保留 2 位小数，小时数保留 1~2 位。

## 8. 安全与备份

- **PIN 锁**：首次设置时输入 4~6 位 PIN；用 Web Crypto（PBKDF2/SHA-256 + 随机盐）存哈希，不存明文；App 启动或切后台超过 1 分钟回前台时要求输入；输错可重置（重置会清空数据，需二次确认）。
- **无网络**：除首次加载静态文件外，应用运行期间不发起任何网络请求；清单内可加 CSP 限制。
- **备份**：导出 Excel 包含「上课记录」「课程类型」sheet；恢复时按内容导入，提供两种模式：**合并**（上课记录按记录 id 去重后追加，课程类型按名称合并）或**覆盖**（先清空本地记录与课程类型再导入）；PIN 不导出。

## 9. 移动端体验设计（布局与交互规范）

- **视口与安全区**：`viewport-fit=cover`，适配刘海屏/底部横条（`env(safe-area-inset-*)`）。
- **布局**：单列流式布局，最大内容宽度 480px 居中；底部 Tab 栏 48~56px 高、带安全区；顶部摘要卡吸顶可滚动。
- **触控目标**：所有可点元素 ≥ 44×44px（推荐 48px）；列表行间距宽松。
- **表单**：日期/时间用原生 `input[type=date/time]` 选择器（iOS 滚轮、Android 日历）；数字键盘（`inputmode=decimal`）；编辑用 Bottom Sheet，避免跳页。
- **手势**：列表行左滑出现操作（取消/删除）；下拉无刷新需求（本地数据，实时更新）。
- **反馈**：按钮点击有按下态；导入/导出有进度与完成提示（Toast）；异常行有醒目色标与错误说明。
- **字体/主题**：系统字体栈；支持浅色/深色（`prefers-color-scheme`）；字号 ≥16px 防 iOS 缩放问题。
- **PWA**：manifest（应用名"课时薪资"、图标、独立窗口、深色状态栏）、离线缓存、安装引导提示（Android 自动、iOS 手动说明）。
- **可访问性**：对比度、标签、focus 状态、触屏区域不重叠。

## 10. 部署（一次性）

1. `npm run build` 生成 `dist/` 静态文件。
2. 推送到 GitHub Pages 或 Cloudflare Pages（免费 HTTPS）。
3. 手机浏览器打开网址 → Android 自动提示"添加到主屏幕"；iPhone 用 Safari 分享 → "添加到主屏幕"。
4. 安装后断网可用；数据均在手机本地。

## 11. 范围外（YAGNI，暂不做）

- 日历视图、图表可视化（先做分组列表）
- 多端实时同步（备份/恢复即可）
