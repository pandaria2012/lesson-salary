## 1. 小程序名称

```
课时记账本
```

- 字符数：5 个中文 × 2 = **10 字符**（规则要求 4~30 字符）✓
- **为什么不用「课时薪资」**：微信对金融类目敏感，名称含"薪资/工资/收入/薪酬"易被要求补金融资质或直接驳回；且个人主体无法开通微信支付，金融方向没有出路。本应用本质是个人课时记账工具，"记账本"更准确也更安全。

## 2. 小程序简称（选填，用于任务栏展示）

```
课时记账
```

- 8 字符（规则要求 4~10 字符）✓
- 规则要求**必须从名称中按顺序取字**。名称「课时记账本」取前 4 字 = 「课时记账」，顺序正确 ✓
- 备选：`记账本`（6 字符）、`账本`（4 字符）
- ⚠️ 不可用 `课时本` —— 跳过了"记账"，不符合"按顺序选取"规则
- ⚠️ 不可用 `课时记账本` —— 与全名相同，通常不允许

## 4. 小程序介绍

**首选版**（约 84 字符，若页面按"中文=1 字符"计数则在 120 以内）：

```
面向老师的课时记录与课酬统计工具。支持 Excel 课程表导入、按月汇总课时与课酬、日历视图、数据备份与恢复。所有数据仅保存在本机，不联网、不上传，无需注册即可使用。
```

**保底短版**（约 55 字符；即使页面按"中文=2 字符"计也只有约 105，必定 ≤120）：

```
老师的课时记录与课酬统计工具。支持 Excel 导入、按月汇总、日历视图与数据备份。数据仅存本机，不联网、不上传。
```

> 名称/简称页明确写了"一个中文等于 2 个字符"，但介绍页只显示 `0/120` 未说明计数方式。**以页面实时计数器为准**：若首选版超限就换保底短版。

**文案里刻意保留的三句话**：`数据仅保存在本机`、`不联网、不上传`、`无需注册`。

这三句是应对隐私合规审核的关键，也是本应用最大的合规优势 —— 个人主体做纯本地工具，数据不出设备，无需申报收集个人信息（见设计文档 §7、§8）。
