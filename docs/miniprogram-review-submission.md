```
首个版本上线。主要功能：上课记录录入与编辑，支持补录、标记取消与删除；Excel 课程表导入，含列自动识别、逐行勾选、重复检测与整批撤销；月度汇总统计，可按学生、课程类型、教学形式分组；月报导出 Excel；数据全量备份与恢复；日历与列表双视图。所有数据仅保存在用户设备本地，不联网、不上传，无需注册登录。
```

若想更短，用这个（**85 字**）：

```
首个版本。支持上课记录录入与编辑、Excel 课程表导入（含预览与重复检测）、按月汇总统计、月报导出、数据备份与恢复、日历视图。数据仅保存在本机，不联网不上传，无需登录。
```

## 4. 「未采集用户隐私」的依据（已核实）

代码层面确认（可复现：`grep` 全部 `wx.` 调用）：

**实际使用的全部 wx API**

```
wx.chooseMessageFile     文件选择（用户主动发起，不采集信息）
wx.env / wx.getFileSystemManager / wx.openDocument / wx.shareFileMessage   文件读写
wx.getStorageInfoSync / getStorageSync / setStorageSync / removeStorageSync  本机存储
wx.showLoading / hideLoading / showModal / showToast  界面提示
wx.navigateTo / switchTab   页面跳转
```

**不存在的东西**

- ❌ 无 `wx.request` / `uploadFile` / `downloadFile` / `connectSocket` —— 没有任何网络请求
- ❌ 无 `getUserProfile` / `getUserInfo` / `getPhoneNumber` / `getLocation` / `chooseImage` 等收集类接口
- ❌ `app.json` 中无 `requiredPrivateInfos` 声明

结论：数据自始至终只存在于用户自己的设备上，开发者接触不到任何用户信息，选「未采集用户隐私」属实。

## 6. 遗留风险（提交前务必知悉）

### R1. 真机 `chooseMessageFile` 未验证

**这是导入功能唯一未经真机验证的环节。** 自动化测试中该系统文件选择框始终是 mock 的。
建议先用「体验版」在手机上实测：把 Excel 发到「文件传输助手」→ 小程序内「从聊天记录选择 Excel」。

### R2. 审核员无法体验 Excel 导入

从聊天记录选文件需要事先有文件，审核员通常不会造。已通过截图缓解（第 4、9 张）。

### R3. 首次打开是空态

纯本地架构的必然结果。若被以「功能过于简单」驳回，可考虑增加「载入示例数据」入口（一次性写入演示记录，写入前提示、可一键清除）。**当前版本未实现此项。**

### R4. ICP 备案

备案是小程序对外发布的上架前置，与代码无关但会卡住发布流程，建议尽早启动。
